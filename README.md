<h2>Sinopsis:</h2>
Kheil, seorang murid pindahan berpenampilan sederhana, ditempatkan di meja paling belakang kelas pada hari pertamanya. Dari sana ia tertarik pada Amira, siswi pemain biola di barisan depan. Konflik dengan Rendy si pembuli menjadi awal perkenalan Kheil dengan Amira, yang berlanjut lewat pertemuan di ruang musik dan ajakan berduet untuk pentas seni sekolah.
